This is a quick redesign of the IRCTC eQuery landing page. The original page works, but it feels dated and a bit hard to use. I focused on making it cleaner, more modern, and easier to interact with—without changing the core idea of the page.

---

## Before vs After

**Before**
- Minimal styling, weak visual hierarchy
- No clear feedback on hover/focus
- Static, unfriendly CAPTCHA
- Navigation wasn’t obvious

**After**
- Clean, train-themed background with a soft overlay
- Clear visual hierarchy and spacing
- Futuristic, accessible form with smooth hover/focus states
- Random CAPTCHA with a reload button
- Simple top navigation (Home, Contact, Help) with interactive hover

## What I Changed (Design Goals)

- **Clarity:** Bigger type, better spacing, and clear labels.
- **Feedback:** Inputs and buttons respond on hover/focus so users feel in control.
- **Trust:** Subtle shadows, consistent colors, and a stable layout.
- **Relevance:** Indian train background to match the product context.
- **Little Delight:** Neon/glassmorphism touches to make it feel current (but not distracting).

---

## Tech & Structure

- **Stack:** HTML, CSS, JavaScript (no frameworks)
- **Files:** `index.html`, `style.css`, `script.js`, `/images`
- **Captcha:** Random string generator + reload button
- **Accessibility:** Good contrast, large clickable areas, keyboard focus states
